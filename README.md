# Outbreak Investigation for Hospital Managers

A one-hour session for Masters in Hospital Management students. It follows one outbreak in a hospital staff canteen from the first sick call to the final report.

## Session objectives

By the end of the session, students will be able to:

1. Define an outbreak, a cluster and a baseline, and judge whether a rise in cases is real.
2. List the steps of an outbreak investigation and explain why control starts on day one.
3. Write a case definition and build a line list.
4. Read an epidemic curve and use the incubation period to estimate when exposure happened.
5. Calculate and interpret attack rates and relative risk, and recognise confounding.
6. Describe the manager's role in control, staff exclusion, communication and IDSP reporting.
7. Apply the same steps to a healthcare-associated infection cluster, and list what a hospital should have in place before the next outbreak.
